## 架构与影响层
Engine 拥有资格、案件流程、人员分配、证据清单与决定校验。S3 Object Lock 适配器保存加密证据。合约拥有冻结、费用托管和最终叶子分配。管理 BFF/Web 只暴露限域操作。

## 组件/模块边界
拆分资格、案件/主张、截止时间、冲突、证据、和解、决定、复核、分配构建、信誉与管理修复模块。

## API 或接口契约
版本化命令绑定案件、主张、assignment/交付、当事人、触发事件、策略、证据根、冻结根/叶子、判付、费用、nonce 和过期时间。证据访问使用短期限域授权。

## 数据模型与迁移
追加案件、主张/反请求、资格快照、软锁、证据对象/清单/访问、人员分配/冲突、决定/复核、冻结叶子、分配指令/结果与管理审计操作。

## 状态、失败、重试与并发
使用单活动容器唯一约束与独立主张身份。截止作业通过比较设置/幂等迁移。链上确认控制冻结/分配状态。全部稳定叶子结果与争议费处置完成后才可最终化。

## 安全与隐私
在分配时和操作时强制职责分离与冲突校验。证据使用每案信封加密；WORM 和清单只追加。管理修复只能调用领域命令。

## 可观测性与运维
对截止作业积压、WORM 失败、访问拒绝、冲突、冻结/最终化延迟、叶子缺失、分配失败、DLQ 和对账操作告警。

## 发布、兼容与回滚
资金路径完成后在测试链启用。策略版本保留旧案件语义。回滚可禁用新申请，但不得改变活动案件或证据。

## 技术决策与备选方案
本功能是平台争议处置，不是法律仲裁。合约校验完整分配，而不信任管理员提供的聚合金额。
