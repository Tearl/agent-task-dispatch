# 争议与管理运营 — 需求

## 背景
- 项目：AI Agent 任务交易与分发平台 MVP
- 架构：Engine 拥有资格/证据流程，合约强制执行冻结叶子分配
- 利益相关者：当事人、裁决/复核人员、管理员、财务、法务/隐私与安全团队

## 范围
### 范围内
发布者/Agent 资格、软锁/最终冻结、主张/反请求、WORM 证据、和解、独立初裁/复核、五档判付、完整叶子分配、管理治理/审计/DLQ/对账运营。
### 范围外
法律意义上的仲裁声称与生产保留/合规策略选型。

## 功能需求
- [F-501] Engine 必须计算发布者与 Agent 争议资格；每个 assignment/交付单元最多一个活动案件容器，但独立主张/反请求不得被抢先阻断。
- [F-502] 申请只创建软锁；仅合约冻结确认后进入争议状态并启动计时流程。
- [F-503] 证据清单必须加密、只追加、WORM 支持且受访问控制，覆盖规格、概览、验收、版本、反馈、变更、执行、用量、消息、回调、费用和策略。
- [F-504] 初裁与唯一复核必须校验分配、利益冲突、人员隔离、时间窗、费用授权与审计；平台判付仅允许 0/25/50/75/100，签名和解可使用合法基点。
- [F-505] 分配必须完整、唯一覆盖稳定冻结叶子，不得更改所有者、上限、费用、舍入或账户白名单；概览、外部 allocation、已结算收益和其他任务必须排除。
- [F-506] 管理操作必须使用受控迁移/冲正/追加，不得覆盖证据、账务或状态，不得代签客户交易或读取凭证。
- [F-507] 信誉只能根据最终责任与结果更新，不得因申请本身变更。

## 验收标准
- [AC-501] 不合格、重复、冲突、过早、过期或未授权操作必须失败，且不阻断有效反请求。
- [AC-502] UI 在确认前不得显示已冻结，并必须正确展示全部截止时间与拒绝原因。
- [AC-503] 修改/删除证据、未授权访问或不完整清单必须失败并记录审计。
- [AC-504] 同人复核、第二次复核、无效判付档位和未付费/未授权复核必须失败。
- [AC-505] 遗漏、重复、重排替换、缩减上限、跨账或提前最终化必须失败；完整有效分配必须价值守恒。
- [AC-506] 管理、DLQ 和对账修复路径必须幂等、只追加且完整审计。

## 非功能需求
- 安全/隐私：最小权限、冲突隔离、加密限时访问、WORM 证据且不泄露密钥。
- 可靠性/可观测性：截止时间作业与链上消费者必须幂等；失败进入告警/DLQ，且可安全重放修复。
- 可访问性：案件时间线、证据和决定必须支持键盘与辅助技术。

## 约束与依赖
依赖正式交付与托管结算。裁决/复核人员配置、保留期、费用、角色/多签和合规决策是生产使用门槛。
