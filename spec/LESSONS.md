# SQ 经验记录

- 链、资产、费率、治理和保留期等不可逆决策，必须依赖经版本化确认的产品基线，不得由实现隐式决定。
- 即使 BFF 或 UI 已校验，Engine 仍必须作为授权与幂等的最终权威。
- 依赖 PostgreSQL 事务级 advisory lock 后读取新提交结果的并发协议，应显式固定 `READ COMMITTED`，并在更高会话默认隔离级别下验证等待者的幂等性。
- 公开 nonce 签发应复用活跃 challenge，用钱包级锁与分片原子限流桶实现跨副本边界；限流协调数据可清理，但不得为此删除不可变的 nonce 历史。
- 健康与租约等时效判断必须使用取得领域锁后的数据库时钟；调用方时间戳只能在有界偏差内作为观测值，不能决定权威新鲜度。
- 容量缓存必须在读写边界按未过期租约派生或对账；预留与释放应统一“聚合后租约”的锁顺序，并按 reservation ID 串行化首次幂等请求。
- 发布不可变版本时，聚合更新、领域/审计事件和去重 Outbox 必须在同一事务中提交。
- 凭证持久化接口应在类型层面拒绝明文，只接收 envelope ciphertext、wrapped DEK 与非敏感元数据；确定性幂等摘要也应在进入仓储前清除。
- 凭证 KEK 与幂等 HMAC 密钥必须独立管理，使 KEK 轮换不破坏历史请求的稳定回放；本地启动文档必须提供安全、可执行的密钥生成步骤。
- 截止时间等时变业务校验必须在幂等记录未命中后、事务内使用数据库时钟执行；否则已成功请求在时间边界后的重投会丢失稳定回放语义。
- 聚合资源与可执行操作时，应由 Engine 在同一数据库快照中返回资源、聚合版本和 decision；并用完整状态迁移图校验 action 清单，避免合法迁移不可发现或跨请求混合快照。
- 多阶段 Web 写入开始后必须锁定参与请求哈希的输入；重试复用同一操作 ID 和原始载荷，修改输入必须显式放弃旧操作并生成新 ID。React pending 状态之外还需同步 single-flight guard，避免同一事件循环内的重复提交。
- 可审计推荐必须先版本化冻结召回融合、子项权重、定点精度、并列规则、分数截断和降级结果；硬过滤始终在召回前执行，依赖失败只能减少信号，不能放宽资格与质量门槛。
- 公平抽样需要把 seed 编码、密钥版本、整数随机映射、逐步条件概率和探索资格一并纳入算法版本；读取已有快照与创建新修订必须是不同操作，避免刷新页面隐式重抽。不可变子表还需在父快照封存后禁止追加，只有禁止 UPDATE/DELETE 并不足够。
- 外部 Agent 执行必须拆分稳定的业务逻辑身份和可递增的网络尝试；不确定投递只能重放原 attempt，明确失败或权威 lease 过期才允许获取更大的 fencing token。回调是否新鲜必须同时校验当前 attempt、token 和数据库接收时刻下的 lease 有效期。
- 一次性回调 nonce 应只持久化摘要，并把首次处理结果作为不可变证据保存；相同 payload 可稳定重放，不同 payload 必须冲突。取消、成本停止和过期后的结果只能审计，不能恢复执行或产生可付结果。
- 成本上限必须在权威用量写入时同步执行：累计用量单调、达到上限立即截断和停止，远端上报超额不能转化为事后收费。外部服务返回的自由文本也不应直接进入日志或历史表。
- 概览编排应只接收脱敏简报引用与哈希，不能让“先传完整任务、再要求 Worker 自律脱敏”成为安全边界；引用本身必须是非 bearer secret，短期授权由传输鉴权层按请求签发。
- 客观有效性必须把结果格式、内容哈希、截止时间和平台侧工具审计证据放在同一次不可变判定中。Agent 自报“未写外部系统”不能替代平台工具网关证据，依赖证据暂不可用也不能提前拒付。
- 一次补位需要冻结候选来源、稳定顺序、服务商上限和批次级竞争锁；原失败 allocation 的 release 与补位的新 allocation 必须分别留痕，不能复用资金身份或删除失败历史。
- 旧修订作废时，不仅运行中的概览需要取消；已校验有效但尚未 capture 的 allocation 也必须允许在“批次已 obsolete”这一数据库可验证前提下 release，避免外部资金状态与本地投影分叉。
- allocation 的“预留”不应伪造成资金分录；可用余额应按账面余额减活动预留计算，只有实际捕获才产生平衡 journal。这样 release 只终结预留，不需要制造反向资金流。
- 复式平衡只是最低约束。资金数据库还必须验证 journal 的业务边界：扣款账户等于 allocation 来源、收入接收者与 Agent 一致、外部成本按 allocation 隔离；否则一组数学平衡的分录仍可能完成跨账盗用。
